# 01 蜡烛图基础

## 什么是蜡烛图（K线图）

蜡烛图（Candlestick Chart），又称K线图，起源于18世纪日本米市，由本间宗久发明。它是技术分析中最基础、最重要的图表工具。

## 蜡烛图的构成

一根完整的K线由以下部分组成：

```
    ┌──────┐  ← 上影线
    │ 实体 │  ← 开盘价/收盘价之间的矩形
    └──────┘  ← 下影线
```

### 四个关键价格

| 价格 | 说明 |
|------|------|
| **开盘价** | 当日/周期第一笔成交价 |
| **收盘价** | 当日/周期最后一笔成交价 |
| **最高价** | 当日/周期最高成交价 |
| **最低价** | 当日/周期最低成交价 |

### 阳线 vs 阴线

| 类型 | 颜色（国内） | 颜色（国际） | 含义 |
|------|------------|------------|------|
| **阳线** | 红色 | 绿色 | 收盘价 > 开盘价，上涨 |
| **阴线** | 绿色 | 红色 | 收盘价 < 开盘价，下跌 |

> 💡 **注意**：国内（A股）和国际（美股等）的颜色习惯相反，看盘时要注意区分。

## 实体大小与影线长度的含义

### 实体大小

| 实体特征 | 市场含义 |
|---------|---------|
| 大阳线实体 | 买方力量强劲，上涨动能足 |
| 大阴线实体 | 卖方力量强劲，下跌动能足 |
| 小实体（十字星） | 多空力量均衡，可能变盘 |

### 影线长度

| 影线特征 | 市场含义 |
|---------|---------|
| 长上影线 | 上方抛压重，上涨遇阻 |
| 长下影线 | 下方有支撑，下跌受阻 |
| 无影线（光头光脚） | 单边走势极强势 |

## 常用时间周期

| 周期 | 适用场景 |
|------|---------|
| 日线（D） | 中长期趋势判断 |
| 60分钟 | 短线波段操作 |
| 30分钟 | 日内交易参考 |
| 周线/月线 | 大趋势方向判断 |

## 学习心得

> 蜡烛图不是预测工具，而是**市场情绪的翻译器**。单根K线意义有限，必须结合位置、成交量和趋势综合判断。
