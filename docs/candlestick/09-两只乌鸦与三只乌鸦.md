# 两只乌鸦与三只乌鸦：多头溃败的多日记录

> **核心命题**：乌鸦形态（Crows）是**连续阴线家族**的顶部反转信号——三只乌鸦是"连续三天单边溃败"，两只乌鸦是"多头两天的攻势被逐口蚕食"。它们的共同本质：**市价卖单的净流量连续多日压过市价买单，且多头毫无像样的反攻**。如果说启明星/黄昏星记录的是"刹车-犹豫-掉头"，乌鸦形态记录的就是"掉头之后，溃败如何持续"。

---

## 一、三只乌鸦（Three Black Crows）：连续三天的单边溃败

### 形态定义

三只乌鸦是**三根连续的长阴线**，出现在上涨趋势顶部：

```
第1天      第2天      第3天
  │          │          │
  ├──        ├──        ├── ← 收盘接近最低价
  │          │          │
  │ 阴线     │ 阴线     │ 阴线
  │          │          │
  ├──        ├──        ├── ← 每根开盘都在前一根实体之内
  │          │          │
  └──────────┴──────────┴── ← 收盘价依次降低
```

| 特征 | 说明 |
|------|------|
| 三根**长阴线** | 实体大，收盘接近最低价，几乎无下影线 |
| 开盘位置 | 每根开盘价都在前一根**实体之内**（或接近前一根收盘） |
| 收盘位置 | 三根收盘价**依次降低**，低点不断下移 |
| 出现位置 | 上涨趋势**顶部**（或高位横盘后） |
| 含义 | 多头持续溃败 → 看跌 |

### 订单簿视角：净流量连续三天一边倒

```
市价卖单净流量：  第1天  ██████
                  第2天  ████████
                  第3天  ██████████  ← 越来越强
市价买单净流量：  第1天  ██
                  第2天  █
                  第3天  ▏            ← 越来越弱
```

- **第1天**：市价卖单开始占优，多头退守。
- **第2天**：开盘在前一天实体之内（多头连高开都做不到），卖压增强，多头无力反攻。
- **第3天**：开盘继续走低，卖压持续，收盘接近最低——**多头三天没有任何一次像样的反攻**（几乎无下影线 = 没有承接）。

> **核心问题**：为什么三只乌鸦可信？因为它记录的不是"某一天跌了"，而是"**连续三天，卖方力量一天比一天强，买方连反攻的迹象都没有**"。趋势反转后能持续下跌，正是"净流量持续一边倒"的直接体现。

### 强度：为什么比单根/双根形态更强

| 维度 | 单根阴线 | 看跌吞没 | 三只乌鸦 |
|------|---------|---------|---------|
| 天数 | 1天 | 2天 | **3天** |
| 证据 | 一天抛压 | 两天对比 | **三天连续溃败** |
| 反攻迹象 | 可能次日反攻 | 可能次日反攻 | **三天零反攻** |
| 信号强度 | 弱 | 中 | **强** |

> **三只乌鸦的"狠"在于持续性**——它证明了卖方的力量不是"一天的事"，而是能连续三天维持。这在订单簿上意味着：市价卖单不是一次性涌出，而是**源源不断**。

## 二、两只乌鸦（Two Crows）：多头败退的两步记录

### 形态定义

名字叫"两只乌鸦"，但它其实是**三根K线的组合**（第三根是"第二只乌鸦"，前两根是铺垫）：

```
第1天        第2天          第3天
  │            │              │
  │ 长阳线     │  小实体阳线   │  阴线（乌鸦）
  │（多头强势）│（跳空高开但   │ （高开低走，收盘
  │            │  实体缩小）  │   跌入第1天实体）
  │            │              │
```

| 根 | 形态 | 含义 |
|----|------|------|
| 第1根 | **长阳线**，收盘接近最高价 | 多头强势，趋势延续 |
| 第2根 | **跳空高开的阳线**，但实体明显比第1根小 | 多头尝试但**动能减弱**（隐患出现） |
| 第3根 | **阴线**，开盘在第2根实体之内，收盘**跌入第1根实体内部** | 多头被反噬，"第二只乌鸦"落地 |

### 为什么是"两只乌鸦"：多头攻势被逐口吃掉

- **第2根（第一只乌鸦的铺垫）**：跳空高开看似强势，但实体缩小——多头**冲得高、收得小**，动能已经衰减。这是第一个警告。
- **第3根（第二只乌鸦）**：高开后直接低走，阴线吞掉第2根全部战果，还深入第1根实体——**多头两天的战果，被一天反噬**。

> **核心问题**：两只乌鸦记录的是"多头攻势的逐级瓦解"——第2天高开低走收小实体（动能减），第3天高开低走收阴线（被反噬）。它不是突然崩溃，而是**两步败退**。

### 与黄昏星的对比

两只乌鸦和黄昏星是近亲，都出现在顶部、都是三根K线：

| 维度 | 黄昏星 | 两只乌鸦 |
|------|--------|---------|
| 第2根 | **小实体星线**（实体极小，十字/流星） | **跳空高开的小阳线**（还有实体） |
| 第2根含义 | 动能枯竭、犹豫 | 动能减弱但多头仍在尝试 |
| 第3根 | 长阴线跌入第1根实体 | 阴线跌入第1根实体 |
| 信号强度 | 强（星线=彻底犹豫） | 中（第2根还留着多头痕迹） |

> **两只乌鸦比黄昏星弱一档**——因为它的第2根是阳线（多头还在挣扎），不像黄昏星的星线那样"完全刹车"。它是"犹豫但未死心"的版本。

## 三、两只乌鸦与三只乌鸦的关系

两者都是"连续阴线"家族，但叙事不同：

| 维度 | 两只乌鸦 | 三只乌鸦 |
|------|---------|---------|
| K线构成 | 阳+阳（小）+阴 | 阴+阴+阴 |
| 叙事 | **多头进攻→被反噬**（转折型） | **多头持续溃败**（延续型） |
| 本质 | 高开低走的两步败退 | 连续三天的单边碾压 |
| 强度 | 中 | **强** |
| 与已学形态 | ≈ 黄昏星的弱化版 | ≈ 三连阴的吞没/看跌延续 |

> 两者其实是同一逻辑的不同阶段：**两只乌鸦是"溃败的开始"（多头还能挣扎一天），三只乌鸦是"溃败的确认"（多头已彻底放弃）。** 实战中，两只乌鸦出现后如果继续收阴，往往就演化成三只乌鸦。

---

## 四、与已学形态的联系

乌鸦形态不是孤立的新形态，它是前面所学逻辑的"多日扩展"：

| 已学形态 | 与乌鸦形态的联系 |
|---------|----------------|
| **看跌吞没** | 三只乌鸦 ≈ 三根连续的小吞没（每天开盘被前日收盘压制） |
| **黄昏星** | 两只乌鸦 ≈ 黄昏星的变体（第2根不是星线而是小阳线） |
| **乌云盖顶** | 乌鸦形态的第1天常以乌云盖顶式的大阴线开始 |
| **三只乌鸦的反面** | 三根连续长阳线 = **红三兵**（底部看涨的镜像，未来可单独成篇） |

> **统一视角**：所有反转形态都是"市价单净流量反转"的记录——单根看到苗头，双根看到对比，三根乌鸦看到了**持续性**。

## 五、强度判断与后续确认

### 强度因素

| 形态 | 什么情况下更强 |
|------|--------------|
| **三只乌鸦** | 三根实体都长、收盘都在最低附近（无下影）；位置在涨幅巨大处；**放量**（真实抛压）；第三根实体最长（卖压递增） |
| **两只乌鸦** | 第2根跳空缺口越大、实体越小越强；第3根深入第1根实体越深越强；位置在趋势末端加分 |

### 后续确认

| 后续走势 | 乌鸦形态（看跌）验证 |
|---------|-------------------|
| **反弹到乌鸦形态高点受阻回落** | ✅ 反转延续（阻力确认） |
| **放量突破乌鸦形态最高点** | ❌ 反转失败，重回上涨 |
| **低位横盘不创新低** | ⚠️ 观望，等待方向 |

> 乌鸦形态本身已含较强确认（多日连续），但**反转的持续性**仍要等反弹来验证——反弹不过乌鸦高点，才是真正的下跌趋势。

---

## 六、实战要点

1. **三只乌鸦可更果断**：连续三天单边溃败，信号强于单根/双根形态，确认后可顺势做空。
2. **两只乌鸦要等第三根**：前两根只是"铺垫"，必须等第3根阴线（第二只乌鸦）出现才有意义。
3. **看每天的开盘**：开盘是否被前一日实体压制（高开无力）——这是乌鸦形态"卖方持续掌控"的关键证据。
4. **结合位置**：高位/涨幅巨大处的乌鸦最可信，低位横盘中的三根阴线可能只是震荡。
5. **止损放形态高点**：做空后止损放在乌鸦形态最高点上方（两只乌鸦看第2根跳空高点，三只乌鸦看第1根开盘价）。

---

## 七、总结

> **三只乌鸦 = 连续三天市价卖单净流量一边倒，多头零反攻——溃败的确认（强）。**
> **两只乌鸦 = 多头跳空高开但动能减弱，随后一天被反噬——溃败的开始（中）。**

**回到订单簿的底层铁律**：

```
乌鸦形态 = 市价卖单净流量连续多日压过市价买单
连续无下影线 = 连续无承接 = 买方连反攻的迹象都没有
溃败一旦持续，就是趋势反转的确认，而非猜测
方向仍由市价单净流量决定，持续性是它最硬的证据
```

乌鸦形态补全了反转工具箱的"持续性"维度——之前学的形态大多记录"反转发生的瞬间"，乌鸦形态记录"反转发生之后的持续溃败"。至此，从瞬间到持续，反转形态的全谱系已经覆盖完毕。
