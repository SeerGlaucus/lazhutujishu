# 刺透形态：未完成的看涨吞没

> **核心命题**：刺透形态是"未完成的看涨吞没"——两根K线里，第一根是长阴线，第二根低开高走、收盘刺入第一根实体的上半部分，但尚未完全覆盖。它记录的是：空头乘胜追击时被反打，但阵地还在；多头反击成功，但尚未全歼。判断它的看涨成色，取决于一个根本问题——**当天的主动买单从哪来、为什么超过了主动卖单**。

---

## 一、形态定义：两根K线

| 根 | 形态 | 含义 |
|----|------|------|
| 第一根 | **长阴线**，收盘接近最低价 | 空头全天强势进攻 |
| 第二根 | **低开**后大幅上涨，收盘**刺入第一根实体的上半部分**（但未完全覆盖） | 空头下杀失败，多头强力反击 |

关键在**第二根收盘的位置**。它决定了这根K线到底"是不是刺透形态"，以及强度有多高：

```
第一根阴线实体：
    ┌─────────┐
    │         │ ← 最高价
    │         │
    │  实体   │ ← 中点（50% 分界线）
    │         │
    │         │ ← 最低价
    └─────────┘
```

- 阳线收盘只反弹到**中点下、下半区** → 不是刺透形态，只是普通反抽。
- 阳线收盘**刺入上半区（越过 50%）** → 刺透形态成立，越深越强。
- 阳线收盘**突破第一天开盘价（完全覆盖）** → 升级为**看涨吞没**。

**所以刺透形态 = "多头反击成功，但没完全收复第一天全部失地"。** 这正是它和看涨吞没的本质区别。

---

## 二、收盘位置：强度的连续谱

刺透形态不是"有/无"的二元信号，而是一条连续强度谱——**收盘深度 = 多头反击的彻底程度 = 空头被套的人数规模**。

| 第二根收盘位置 | 强度 | 解读 |
|---------------|------|------|
| 只反弹到下半区 | ❌ 不算刺透形态 | 普通反抽，空头仍主导 |
| 反弹到 50% 中点 | ⚠️ 弱刺透形态 | 勉强成立，需强确认 |
| 刺入上半区（50%~70%） | ✅ 标准刺透形态 | 中强度，等确认 |
| 接近第一天开盘价（80%~99%） | ✅✅ 强刺透形态 | 接近吞没，可轻仓试 |
| 突破第一天开盘价 | 升级为看涨吞没 | 强信号 |

刺得越深，第一天中低位卖出的人被套得越多，后续回踩到成本区时"回本即买"（空头回补）的买盘越强。

---

## 三、订单簿视角：两天博弈

### 第一天：空头全胜

```
价格轴
  ↑
  │   ← 开盘价：上方 Ask 厚重，全天几乎不反弹
  │
  │   ← 长阴线实体：连续 Market Sell 扫掉买一买二买三
  │
  │   ← 收盘接近最低价：空头把下方 Bid 墙一路吃穿
  └─
```

第一天空头的进攻是压倒性的：主动卖单（Market Sell）把下方的限价买单（Bid）逐层吃掉，收盘停在最低附近——下方承接被暂时打穿，空头占据绝对优势。

### 第二天：低开遇撑，主动买单反攻

```
价格轴
  ↑
  ├─ 第一天开盘价（尚未突破，所以是刺透形态不是吞没）
  │        └─ 收盘刺入第一天实体上半区
  │
  │   ← 阳线实体：价格收复第一天多个成交密集区
  │
  │   ← 盘中：主动买单（Market Buy）集中涌出
  │
  ├─ 低开：空头惯性还在，恐慌盘在开盘涌出
  └─
```

| 阶段 | 订单簿动态 | 多空含义 |
|-----|-----------|---------|
| **低开** | 空头惯性下杀，开盘价直接砸在下方 | 空头最后的冲刺，恐慌盘涌出 |
| **滞跌** | 下方埋伏的 Bid 墙（价值盘+空头回补盘+抄底盘挂的限价买单）托住下跌 | 价格跌不动 |
| **转折** | 主动买单（Market Buy）进场，从"挂着等"变成"市价抢" | 多头主动进攻 |
| **回升** | 价格连续上涨，收复第一天实体内部 | 买方力量压过卖方 |

## 四、方向与速度：上涨的本质是市价买单

这一节是理解刺透形态（以及一切上涨K线）的关键，需要把两个概念彻底分开：

| 订单类型 | 性质 | 作用 |
|---------|------|------|
| **限价买单（Bid 墙）** | 被动、挂在墙上等成交 | 只能形成**支撑**——让价格跌不动，**不能把价格往上推** |
| **市价买单（Market Buy）** | 主动、立即成交 | 才是真正**拉升**的力量，把价格往上推 |

> **墙是"托"的，不是"推"的。** 价格撞上 Bid 墙，结果是"下不去、滞跌"，而不是"涨起来"。要涨起来，必须有新的主动买单进场。

所以刺透形态第二天的上涨，分两步看：

1. **低开撞墙**：空头惯性下杀，撞上埋伏的 Bid 墙 → 价格**跌不动**（墙的被动支撑）。
2. **滞跌引发主动买入**：墙外的买方看到"价格卡住、卖盘衰竭"，判断"再等就买不到这个价了"，于是**从挂限价单等成交，切换成下市价单抢筹**——抄底盘、空头回补盘、新多头一起动手。

> 墙本身不拉升，但**墙造成的滞跌会诱导墙外的买方主动抢筹**。这就是从"支撑"到"买盘"的转化机制。

**但必须强调：墙不是上涨的必要条件。** 只要市价买单的力量超过市价卖单，没有墙照样涨——比如一根低开的阳线，开盘价就是最低价，根本没有"滞跌横盘"的过程，直接往上拉。这就是"没有墙、纯靠市价买盘碾压市价卖盘"的上涨。

所以更本质的表述是：

> **刺透形态（以及一切上涨K线）的成立，只需要一件事：当天市价买盘的力量 > 市价卖盘的力量。** 有没有墙、是否先滞跌，都只是场景细节，不是成立条件。

---

## 五、与看涨吞没的关系：打退 vs 全歼

刺透形态和看涨吞没是同一场战役的两种结局：

| 维度 | 刺透形态 | 看涨吞没 |
|------|---------|---------|
| 阳线收盘位置 | 刺入第一天实体**上半区** | **突破**第一天开盘价（完全覆盖） |
| 被套者范围 | 第一天**中低位**卖出者被套 | 第一天**全体**卖出者被套 |
| 多头战果 | 反攻成功，未全歼 | 全歼 |
| 信号强度 | 中（**必须**后续确认） | 强（当天可轻仓试） |
| 本质 | 空头的攻势被反打，但阵地还在 | 空头的阵地被全部收复 |

> **一句话：刺透形态是"多头把空头打退了"，看涨吞没是"多头把空头全歼了"。** 所以刺透形态的可信度天然低一档——空头还守着"第一天最高价"这条防线。

---

## 六、后续确认

正因为阳线没有完全覆盖，刺透形态**必须**靠后续K线验证：

| 后续走势 | 验证 |
|---------|------|
| 次日高开高走 / 突破第一天最高价 | ✅ 刺透形态确认，多头接管 |
| 次日收阴、重新跌破中点 | ❌ 刺透形态失效，仍是空头主导 |
| 回踩到第一天上半区获支撑企稳 | ⚠️ 偏多，观察是否突破 |

> 判断"价格有没有有效突破"，不能只看影线尖端点一下，要看**收盘价是否突破**，或**那个价位有没有放量成交**——影线尖端可能只是"价差瞬间拉宽 + 一笔小单"造成的流动性假象。

---

## 七、实战要点

1. **看强度，不看有无**：先看第二根阳线收盘刺到第一天实体的哪个位置——上半区才算数，越深越强，突破开盘价就直接按看涨吞没处理。

2. **看主动买单的来源**：上涨是否由"抄底盘/空头回补盘/新多头主动抢筹"推动，而不是"跌不动后的自然反抽"。主动抢筹越坚决，看涨越可信。

3. **必须等确认**：刺透形态比吞没弱，空头的防线（第一天最高价）还没丢，等次日突破或回踩企稳再动手。

4. **用止损扛，而不是用等待躲**：强信号（收盘深、放量、趋势末端）可以当天进，止损放在第二根阳线低点下方一点；弱信号则等确认。

---

## 八、总结

> **刺透形态 = 空头长阴后乘胜追击（低开），撞上下方埋伏的 Bid 墙而滞跌，随后抄底盘/空头回补盘/新多头从"挂单等"转为"市价抢"，价格被主动买单拉回第一天实体内部——但多头只"打退了"空头，没有"全歼"（否则就是看涨吞没）。**
>
> 它标记出的信号是：**第一天中低位做空的人被套了**。这批被套者在后续回踩到成本区时的"回本即买"（空头回补），才是它真正看涨的力量来源——而这需要后续K线去触发和确认。

**回到订单簿的底层铁律**（详见「00 订单簿基础」）：

```
市价单 → 决定方向（净流谁大往哪走）
限价单 → 决定速度与成交价（墙的厚薄、撤单滞后）
上涨的本质 = 市价买单净流量 > 市价卖单净流量
墙只是场景，不是原因
```

刺透形态和其他形态一样，本质都是订单簿上买卖力量博弈的**影子**。看懂了"谁在买、为什么买"，才不会被一根阳线的形状迷惑。
