# 乌云盖顶：未完成的看跌吞没

> **核心命题**：乌云盖顶是"未完成的看跌吞没"——两根K线里，第一根是长阳线，第二根高开低走、收盘跌入第一根实体的下半部分，但尚未完全覆盖。它记录的是：多头乘胜追击时被反打，但阵地还在；空头反击成功，但尚未全歼。判断它的看跌成色，取决于一个根本问题——**当天的主动卖单从哪来、为什么超过了主动买单**。

---

## 一、形态定义：两根K线

| 根 | 形态 | 含义 |
|----|------|------|
| 第一根 | **长阳线**，收盘接近最高价 | 多头全天强势进攻 |
| 第二根 | **高开**后大幅下跌，收盘**跌入第一根实体的下半部分**（但未完全覆盖） | 多头冲高失败，空头强力反击 |

关键在**第二根收盘的位置**。它决定了这根K线到底"是不是乌云盖顶"，以及强度有多高：

```
第一根阳线实体：
    ┌─────────┐
    │         │ ← 最高价
    │         │
    │  实体   │ ← 中点（50% 分界线）
    │         │
    │         │ ← 最低价
    └─────────┘
```

- 阴线收盘只跌到**中点上、上半区** → 不是乌云盖顶，只是普通回调。
- 阴线收盘**跌入下半区（越过 50%）** → 乌云盖顶成立，越深越强。
- 阴线收盘**跌破第一天开盘价（完全覆盖）** → 升级为**看跌吞没**。

**所以乌云盖顶 = "空头反击成功，但没完全吃掉第一天全部战果"。** 这正是它和吞没形态的本质区别。

---

## 二、收盘位置：强度的连续谱

乌云盖顶不是"有/无"的二元信号，而是一条连续强度谱——**收盘深度 = 空头反击的彻底程度 = 被套多头的人数规模**。

| 第二根收盘位置 | 强度 | 解读 |
|---------------|------|------|
| 只跌入上半区 | ❌ 不算乌云盖顶 | 普通回调，多头仍主导 |
| 跌到 50% 中点 | ⚠️ 弱乌云盖顶 | 勉强成立，需强确认 |
| 跌入下半区（50%~70%） | ✅ 标准乌云盖顶 | 中强度，等确认 |
| 接近第一天开盘价（80%~99%） | ✅✅ 强乌云盖顶 | 接近吞没，可轻仓试 |
| 跌破第一天开盘价 | 升级为看跌吞没 | 强信号 |

跌得越深，第一天中高位买入的人被套得越多，后续反弹到成本区时"回本即卖"的解套抛压越大。

---

## 三、订单簿视角：两天博弈

### 第一天：多头全胜

```
价格轴
  ↑
  │   ← 收盘接近最高价：多头把上方 Ask 墙一路吃光
  │
  │   ← 长阳线实体：连续 Market Buy 扫掉卖一卖二卖三
  │
  │   ← 开盘价：下方 Bid 坚挺，全天几乎不回撤
  └─
```

第一天多头的进攻是压倒性的：主动买单（Market Buy）把上方的限价卖单（Ask）逐层吃掉，收盘停在最高附近——上方抛压被暂时清空，多头占据绝对优势。

### 第二天：高开遇阻，主动卖单反攻

```
价格轴
  ↑
  ├─ 高开：多头惯性还在，FOMO 追高盘在开盘涌入
  │
  │   ← 盘中：主动卖单（Market Sell）集中涌出
  │
  │   ← 阴线实体：价格跌穿第一天多个成交密集区
  │        └─ 收盘跌入第一天实体下半区
  ├─ 第一天开盘价（尚未跌破，所以是乌云盖顶不是吞没）
  └─
```

| 阶段 | 订单簿动态 | 多空含义 |
|-----|-----------|---------|
| **高开** | 多头惯性追高，开盘价直接顶在上方 | 多头最后的冲刺，FOMO 盘进场 |
| **滞涨** | 上方埋伏的 Ask 墙（止盈盘+空头+解套盘挂的限价卖单）挡住上涨 | 价格涨不动 |
| **转折** | 主动卖单（Market Sell）进场，从"挂着等"变成"市价砸" | 空头主动进攻 |
| **回落** | 价格连续下跌，跌穿第一天实体内部 | 卖方力量压过买方 |

---

## 四、方向与速度：下跌的本质是市价卖单

这一节是理解乌云盖顶（以及一切下跌K线）的关键，需要把两个概念彻底分开：

| 订单类型 | 性质 | 作用 |
|---------|------|------|
| **限价卖单（Ask 墙）** | 被动、挂在墙上等成交 | 只能形成**阻力**——让价格涨不动，**不能把价格往下推** |
| **市价卖单（Market Sell）** | 主动、立即成交 | 才是真正**砸盘**的力量，把价格往下打 |

> **墙是"拦"的，不是"推"的。** 价格撞上 Ask 墙，结果是"上不去、滞涨"，而不是"掉下来"。要掉下来，必须有新的主动卖单进场。

所以乌云盖顶第二天的下跌，分两步看：

1. **高开撞墙**：多头惯性冲高，撞上埋伏的 Ask 墙 → 价格**涨不动**（墙的被动阻力）。
2. **滞涨引发主动抛售**：墙里的卖方看到"价格卡住、买盘衰竭"，判断"再等就卖不出这个价了"，于是**从挂限价单等成交，切换成下市价单砸盘**——止盈盘、解套盘、新空头一起动手。

> 墙本身不砸盘，但**墙造成的滞涨会诱导墙里的人主动砸盘**。这就是从"阻力"到"抛压"的转化机制。

**但必须强调：墙不是下跌的必要条件。** 只要市价卖单的力量超过市价买单，没有墙照样跌——比如一根高开的阴线，开盘价就是最高价，根本没有"滞涨横盘"的过程，直接往下打。这就是"没有墙、纯靠市价卖盘碾压市价买盘"的下跌。

所以更本质的表述是：

> **乌云盖顶（以及一切下跌K线）的成立，只需要一件事：当天市价卖盘的力量 > 市价买盘的力量。** 有没有墙、是否先滞涨，都只是场景细节，不是成立条件。

---

## 五、与看跌吞没的关系：打退 vs 全歼

乌云盖顶和看跌吞没是同一场战役的两种结局：

| 维度 | 乌云盖顶 | 看跌吞没 |
|------|---------|---------|
| 阴线收盘位置 | 跌入第一天实体**下半区** | **跌破**第一天开盘价（完全覆盖） |
| 被套者范围 | 第一天**中高位**买入者被套 | 第一天**全体**买入者被套 |
| 空头战果 | 反攻成功，未全歼 | 全歼 |
| 信号强度 | 中（**必须**后续确认） | 强（当天可轻仓试） |
| 本质 | 多头的攻势被反打，但阵地还在 | 多头的阵地被全部没收 |

> **一句话：乌云盖顶是"空头把多头打退了"，看跌吞没是"空头把多头全歼了"。** 所以乌云盖顶的可信度天然低一档——多头还守着"第一天最低价"这条防线。

---

## 六、后续确认

正因为阴线没有完全覆盖，乌云盖顶**必须**靠后续K线验证：

| 后续走势 | 验证 |
|---------|------|
| 次日低开低走 / 跌破第一天最低价 | ✅ 乌云盖顶确认，空头接管 |
| 次日收阳、重新站上中点 | ❌ 乌云盖顶失效，仍是多头主导 |
| 反弹到第一天下半区受阻回落 | ⚠️ 偏空，观察是否破位 |

> 判断"价格有没有有效跌破"，不能只看影线尖端点一下，要看**收盘价是否跌破**，或**那个价位有没有放量成交**——影线尖端可能只是"价差瞬间拉宽 + 一笔小单"造成的流动性假象。

---

## 七、实战要点

1. **看强度，不看有无**：先看第二根阴线收盘跌到第一天实体的哪个位置——下半区才算数，越深越强，跌破开盘价就直接按看跌吞没处理。

2. **看主动卖单的来源**：下跌是否由"止盈盘/解套盘/新空头主动砸盘"推动，而不是"涨不动后的自然回落"。主动砸盘越坚决，看跌越可信。

3. **必须等确认**：乌云盖顶比吞没弱，多头的防线（第一天最低价）还没丢，等次日跌破或反弹受阻再动手。

4. **用止损扛，而不是用等待躲**：强信号（收盘深、放量、趋势末端）可以当天进，止损放在第二根阴线高点上方一点；弱信号则等确认。

---

## 八、总结

> **乌云盖顶 = 多头长阳后乘胜追击（高开），撞上上方埋伏的 Ask 墙而滞涨，随后止盈盘/解套盘/新空头从"挂单等"转为"市价砸"，价格被主动卖单打回第一天实体内部——但空头只"打退了"多头，没有"全歼"（否则就是看跌吞没）。**
>
> 它标记出的信号是：**第一天中高位追涨的人被套了**。这批被套者在后续反弹到成本区时的"回本即卖"，才是它真正看跌的力量来源——而这需要后续K线去触发和确认。

**回到订单簿的底层铁律**（详见「00 订单簿基础」）：

```
市价单 → 决定方向（净流谁大往哪走）
限价单 → 决定速度与成交价（墙的厚薄、撤单滞后）
下跌的本质 = 市价卖单净流量 > 市价买单净流量
墙只是场景，不是原因
```

乌云盖顶和其他形态一样，本质都是订单簿上买卖力量博弈的**影子**。看懂了"谁在砸、为什么砸"，才不会被一根阴线的形状迷惑。
