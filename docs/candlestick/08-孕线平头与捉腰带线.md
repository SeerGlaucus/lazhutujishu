# 孕线、平头与捉腰带线：犹豫、验证与单边的三种记录

> **核心命题**：孕线、平头形态、捉腰带线是三种"非常规"的反转形态——它们不靠大实体碾压（吞没）、也不靠长影线攻防（锤子/流星），而是分别记录了三种更微妙的力量信号：**孕线记录"力量的骤减"（犹豫），平头记录"同一价位的两次攻防"（验证），捉腰带线记录"开盘即定方向的单边推进"（明确）**。看懂它们，就补全了反转形态的最后一块拼图。

---

## 一、孕线（Harami）：被包裹的犹豫

### 形态定义

孕线（日语"怀孕"之意）是两根K线的组合——**第一根是长实体，第二根小实体完全被包裹在第一根实体之内**：

| 形态 | 第一根 | 第二根 | 出现位置 | 含义 |
|------|--------|--------|---------|------|
| **看涨孕线** | 长**阴**线（空头强势） | 小实体阳/阴，**完全在第一根实体内部** | 下跌趋势底部 | 空头动能衰竭 → 看涨 |
| **看跌孕线** | 长**阳**线（多头强势） | 小实体阳/阴，**完全在第一根实体内部** | 上涨趋势顶部 | 多头动能衰竭 → 看跌 |

```
看跌孕线（顶部）：
  第1天  ┌───────┐ ← 长阳线（多头强势）
         │ ┌───┐ │ ← 第2天小实体被包裹
         │ └───┘ │     （多头犹豫了）
         └───────┘
```

### 订单簿视角：力量"虚胖"的记录

孕线的本质是**原方向力量的骤减**：

- 第1天长实体：市价单净流量一边倒（多头或空头占优），看起来势不可挡。
- 第2天小实体：市价单净流量骤降到接近平衡——**原方向突然推不动了**，价格缩回第1天实体内部。

> **核心问题**：第1天的强势是"真实的力量"还是"虚胖"？第2天的小实体就是答案——**如果第1天的力量是真的，第2天为什么连自己的阵地都守不住？**

这正是孕线和吞没的镜像关系：

| 维度 | 看跌吞没 | 看跌孕线 |
|------|---------|---------|
| 包裹方向 | 第2天**包裹**第1天 | 第2天**被**第1天包裹 |
| 信号 | 多头被**全歼**（强） | 多头**自行衰竭**（弱） |
| 强度 | 强 | **弱**（需确认） |

> 孕线是"原方向自己没劲了"，吞没是"原方向被别人打死了"。**自己衰竭的证据，比被歼灭的证据更弱**——所以孕线必须等确认。

### 变体：十字孕线（Harami Cross）

第二根是**十字星**的孕线叫十字孕线——犹豫的极致版本，反转信号比普通孕线更强：

```
看跌十字孕线：
  第1天  ┌───────┐
         │   ＋   │ ← 十字星（开盘=收盘，完全平衡）
         └───────┘
```

## 二、平头形态（Tweezers）：同一价位的两次攻防

### 形态定义

平头形态是两根（或多根）K线的组合——**关键价位完全相同**：

| 形态 | 特征 | 出现位置 | 含义 |
|------|------|---------|------|
| **平头顶部** | 两根K线**最高价相同**（平头） | 上涨趋势顶部 | 同一价位两次遇阻 → 看跌 |
| **平头底部** | 两根K线**最低价相同**（平头） | 下跌趋势底部 | 同一价位两次获撑 → 看涨 |

```
平头顶部：
  第1天  ──╮    ╭──  ← 最高价相同（平头）
         │ │    │ │
         │ │    │ │  ← 可以是阳线+阴线，或两根阳线等
         └─┘    └─┘

平头底部：
         ┌─┐    ┌─┐
         │ │    │ │
  第1天  ──╯    ╰──  ← 最低价相同（平头）
```

### 订单簿视角：被拒绝两次的价位

平头形态的本质是**同一个价位被验证了两次**：

- **平头顶部**：价格两次冲到同一个高点，两次都被砸回——**那个价位上有一堵厚重的Ask墙**（限价卖单），市价买单两次进攻都失败。
- **平头底部**：价格两次跌到同一个低点，两次都被托住——**那个价位上有一道厚实的Bid墙**（限价买单），市价卖单两次进攻都失败。

> **核心问题**：为什么这个价位两次都过不去/跌不破？答案通常只有两个——要么墙太厚（真实的阻力/支撑），要么攻方太弱（力量已竭）。

### 关键：平头是"放大器"，不是"独立信号"

平头形态很少单独出现，它**经常叠加在其他形态之上**，把原有信号加强：

| 叠加组合 | 效果 |
|---------|------|
| **平头 + 锤子线**（底部） | 下方承接被验证两次，反转信号加强 |
| **平头 + 流星线**（顶部） | 上方抛压被验证两次，反转信号加强 |
| **平头 + 吞没** | 价位验证 + 力量碾压，最强组合之一 |

> **实战要点**：看到平头，先找它叠加了什么形态——平头本身只是"同一个价位被拒两次"的验证记录，真正决定方向的是它叠加的那个形态。

## 三、捉腰带线（Belt Hold）：开盘即定方向

### 形态定义

捉腰带线是**单根K线**——特征是无影线或极短影线，开盘价就是极值：

| 形态 | 特征 | 出现位置 | 含义 |
|------|------|---------|------|
| **看涨捉腰带线** | **开盘价 = 最低价**，长阳实体，无下影线（光头阳线） | 下跌趋势底部 | 开盘即单边推升 → 看涨 |
| **看跌捉腰带线** | **开盘价 = 最高价**，长阴实体，无上影线（光脚阴线） | 上涨趋势顶部 | 开盘即单边下杀 → 看跌 |

```
看涨捉腰带线（底部）：
  ┌───────────┐ ← 收盘接近最高
  │           │
  │  长阳实体 │
  │           │
  ●───────────┘ ← 开盘价 = 最低价（无下影线）
  （开盘即全天最低）
```

### 订单簿视角：从开盘就一边倒

捉腰带线的本质是**开盘即定方向，且全天维持**：

- **看涨捉腰带线**：开盘那一刻，市价买单的净流量就压过市价卖单，而且**全天没有一次像样的回调**（无下影线 = 多头从未被压制）——从开盘一路扫单到收盘。
- **看跌捉腰带线**：镜像，市价卖单从开盘就占优，全天单边下杀。

> **核心问题**：为什么无影线？因为**全天没有任何一方发起过像样的反攻**。影线 = 反攻的记录，无影线 = 没有反攻。这根K线是"从开盘到收盘，一方始终碾压另一方"的纯粹记录。

### 为什么捉腰带线强

对比同样出现在底部的锤子线：

| 维度 | 锤子线 | 看涨捉腰带线 |
|------|--------|-------------|
| 盘中剧情 | 先跌后接（防守反击） | 开盘即涨（单边进攻） |
| 影线 | 长下影 | 无下影 |
| 力量性质 | 防守成功 | **进攻从头到尾** |
| 强度 | 中 | **较强**（但需位置+确认） |

> 捉腰带线是"开盘即单边"的形态，比"先被打再反击"的锤子线更主动。但单根K线仍是"嫌疑"，需要后续确认。

## 四、三种形态的统一视角

把三者放进订单簿框架，它们记录的是三种不同的力量信号：

| 形态 | 记录的信号 | 订单簿本质 | 强度 |
|------|-----------|-----------|------|
| **孕线** | 力量**骤减**（犹豫） | 市价单净流量从一边倒变平衡 | 弱 |
| **平头** | 价位被**验证两次** | 同一价位有厚重限价墙 | 中（需叠加） |
| **捉腰带线** | 开盘即**单边** | 市价单从开盘就一边倒 | 较强 |

```
力量信号谱：
  犹豫（孕线）→ 验证（平头）→ 单边（捉腰带线）→ 碾压（吞没）
  越来越强 →→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→
```

> 它们共同的底层逻辑，仍然回到「00 订单簿基础」的铁律：**方向由市价单净流量决定，墙（限价单）决定速度与成交价**——孕线看净流量骤减，平头看墙的厚度，捉腰带线看净流量从开盘就一边倒。

## 五、强度判断与后续确认

### 强度因素

| 形态 | 什么情况下更强 |
|------|--------------|
| **孕线** | 第2天实体越小越强；**十字孕线**最强；位置在趋势末端加分 |
| **平头** | 叠加锤子/流星/吞没时强；平头处**放量**更可信（真实攻防） |
| **捉腰带线** | 实体越长越强；放量更可信；位置在趋势末端加分 |

### 后续确认（三种形态都适用）

| 后续走势 | 看涨形态（孕线/平头底/捉腰带阳） | 看跌形态（孕线/平头顶/捉腰带阴） |
|---------|-----------------------------|-------------------------------|
| **放量阳线/阴线确认方向** | ✅ 反转确认 | ✅ 反转确认 |
| **突破/跌破形态关键位** | ✅ 反转延续 | ✅ 反转延续 |
| **反向吞没确认K线** | ❌ 反转失败 | ❌ 反转失败 |
| **十字星/小实体** | 观望 | 观望 |

> **三者都是"弱-中"信号**（除了捉腰带线稍强），都必须靠后续K线验证——尤其是孕线（力量自行衰竭），它是最需要确认的形态。

## 六、实战要点

1. **孕线要等确认**：孕线是"原方向自己没劲了"，最弱的信号之一，务必等次日K线表态。
2. **平头找叠加**：平头本身只是"价位验证"，找到它叠加的形态（锤子/流星/吞没）才有方向。
3. **捉腰带线看位置**：开盘即单边的K线在趋势末端才有效，趋势中途出现只是普通大阳/大阴。
4. **三者都要看量**：放量的孕线/平头/捉腰带线才是真实力量，缩量可能是诱多/诱空。
5. **用止损扛，不用等待躲**：确认后进场，止损放在形态关键位外侧（孕线的第1天实体边缘、平头的平头价位、捉腰带线的实体低/高点）。

---

## 七、总结

> **孕线记录"力量的骤减"**——原方向第2天突然推不动了（犹豫，最弱，需确认）。
> **平头记录"同一价位的两次攻防"**——同一个价位被验证两次（验证，需叠加其他形态才有方向）。
> **捉腰带线记录"开盘即定方向的单边推进"**——从开盘就一边倒，全天无像样反攻（明确，较强）。

**回到订单簿的底层铁律**：

```
孕线 = 市价单净流量骤减（力量衰竭的信号）
平头 = 同一价位厚重的限价墙（阻力/支撑被验证）
捉腰带线 = 市价单净流量从开盘就一边倒（单边推进）
方向仍由市价单净流量决定，墙决定速度与成交价
```

三种形态补全了反转工具箱的最后一块拼图——它们不像吞没那样靠碾压、也不像锤子那样靠防守，而是从**犹豫、验证、单边**三个角度捕捉力量反转的蛛丝马迹。至此，从单根到三根、从攻防到犹豫的经典反转形态，已经全部覆盖。
